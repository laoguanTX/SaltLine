# 盐词 · SaltLine

在 Cinnamon 任务栏中显示 SaltPlayer 的逐字歌词，支持圆角专辑封面、封面主题取色和第二行翻译。

## 功能

- 根据播放器原始逐字时间戳连续高亮；长句自动横向滚动。
- 暂停和跳转同步；两句之间保留上一句，避免闪回占位文字。
- 最左侧显示圆角方形专辑封面，自动提取主题色，也可手动设置颜色。
- 翻译固定第二行，过长时省略；自动适应 36/44 像素高的面板。
- 启用模组后自动安装 Cinnamon 小程序，无需单独下载或解压。

## 安装

要求 **Linux 原生 SaltPlayer 1.19.0+、Cinnamon 水平面板**。不支持 Windows / Wine；受限沙箱中的播放器不保证能操作宿主面板。

1. 从本仓库 [Releases](https://github.com/laoguanTX/SaltLine/releases/latest) 下载最新的 `saltline-<版本>.spmod`。
2. SaltPlayer → **创意工坊 → 模组管理 → 导入模组**，选择安装包。
3. 启用 **SaltLine (盐词)**；需要封面时勾选 **读取曲库** 权限。
4. 播放含歌词的歌曲。小程序会自动安装到当前用户目录并添加到首个水平面板。

Steam 创意工坊用户订阅后仍需在模组管理中启用一次。当前仓库未提供已发布的工坊条目链接。

自动安装需要系统 `/usr/bin/python3`、PyGObject 和 Cinnamon 设置架构，常规 Cinnamon 安装通常已有。无需管理员权限。没有水平面板时，先添加水平面板再重新启用模组。

## 设置与显示

右键任务栏歌词 → **配置**，可调整宽度、字号、字体、封面、自动取色、手动颜色、翻译和时间补偿。通过面板编辑模式拖动位置。

逐字效果需要歌曲本身有逐字时间戳，普通逐行歌词只整行高亮。封面读取歌曲的内嵌图片，不联网搜索；无封面或未授权时显示音乐占位图并回退到手动颜色。翻译默认开启，多段翻译合并在第二行。正数时间补偿使歌词提前，负数使其延后。

## 更新与卸载

导入新版包并按播放器提示重新启用或重启，面板脚本会同步更新。重复启用不会重复添加小程序。

- **停用**：移除自动添加的面板条目，保留文件和设置。
- **删除**：清理安装器创建且未被修改的受管理文件；保留用户修改、额外文件及设置。
- **原先手动安装**：更新文件但保留布局，停用和删除时不移除原有手动条目或目录。

## 常见问题

- 出现 `No module named gi`：更新至 1.2.2 或更高版本，重新启用模组；旧版在 Steam 容器内可能调用了缺少桌面依赖的 Python。
- 等待连接：确认模组已启用；查看播放器日志中的 `SaltLine` / `SaltLine Cinnamon` 提示。
- 无封面或取色：确认已授予读取曲库权限，且歌曲含内嵌专辑图片。
- 高亮不同步：暂停后继续或拖动进度重建同步，也可调整时间补偿。首次在播放中启用可能需要约两次进度回调。
- 面板未出现：确认正在使用水平面板，且播放器与桌面属于同一 Linux 用户。

当前只显示一行主歌词；重叠和声选择起始时间最新的一行，RTL 混排填色仍需真实歌曲验证。

## 开发

需要 JDK 25+、Python 3；完整测试另需 Node.js、系统 Python 的 PyGObject 及 Cinnamon 设置架构；安装器同时包含无 GI 备用通道测试。

```bash
python3 scripts/build.py
python3 scripts/test.py
```

构建产物在 `dist/`，本机 JDK 和依赖缓存不进入 Git。详细说明：

## 隐私与验证范围

插件通过当前用户的本机缓存文件传递歌词，不监听网络端口、不下载歌词、不修改歌曲文件。只在当前用户目录安装小程序；遵循 `XDG_DATA_HOME`、`XDG_CACHE_HOME` 和 `XDG_STATE_HOME`。

已通过歌词同步、封面、主题色、15 项安装器回归测试和 Java 嵌入资源安装生命周期测试；Cinnamon 6.6.9 已实际加载和绘制验证。当前版本的 SaltPlayer 内完整启停流程仍需实际导入后验证。
