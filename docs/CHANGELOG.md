# 版本记录

## 1.2.1

- 项目更名为「盐词 · SaltLine」，同步插件和面板中的显示名称。
- 保留原有插件 ID、小程序 UUID、设置和缓存路径，兼容旧版升级。

## 1.2.0

- 将 Cinnamon 面板小程序与安装器嵌入 `.spmod`，启用后自动安装并添加面板条目。
- 版本更新自动重新加载，重复启用不会重复添加。
- 停用与删除按安装记录清理，保留手动布局和用户设置。

## 1.1.0

- 左侧圆角专辑封面与封面主题取色。
- 翻译固定第二行，并适配面板高度。
- 封面后台读取、缩略图缓存与迟到结果保护。

## 1.0.1

- 一句结束后保留高亮至下一句开始，避免闪回曲名或无歌词提示。

## 1.0.0

- 首版逐字歌词桥接与 Cinnamon 面板显示。
